# Prueba 2 · Crear y guardar Pong

Abre un chat nuevo en [el modo de archivos restringidos](../agente-archivos.md). En el chat convencional, el modelo no dispone de herramientas para guardar archivos.

```text
Crea un videojuego Pong completo para dos jugadores, con HTML, CSS y JavaScript en un único archivo.
Quiero controles W/S y flechas arriba/abajo, marcador, botón de reinicio, velocidad progresiva y diseño arcade con colores neón.
Utiliza tus herramientas para crear y guardar index.html dentro de tu carpeta de trabajo autorizada.
No me muestres el código en el chat. Comprueba que el archivo existe y facilítame su ruta absoluta para abrirlo en el navegador.
Si encuentras errores, utiliza las herramientas disponibles para corregirlos.
```

Si la interfaz pide autorización para las herramientas, comprueba que solo aparecen las cuatro de `CloverPong`. Al terminar, abre el `index.html` guardado en la carpeta `CloverPong` del repositorio descargado. La respuesta debe corresponder a un archivo real, no solo a una ruta escrita en el chat. Una nueva ejecución puede generar un juego diferente.
